## 二、内容全解（11 个板块）

### 1. 检索式构建（Query Construction）
- **MeSH 主题词**：用受控词表精确检索，不管原文字怎么写都能命中相关概念
- **布尔运算符必须大写**：`AND` / `OR` / `NOT`（小写会被忽略）
- **词组加引号**：`"heart failure"`；不加引号会被拆成 heart 和 failure 分别检索
- **字段限定标签**：`[Title]`、`[Author]`、`[MeSH Terms]`
  - 示例：`aspirin[Title] AND prevention[MeSH]`
- **截词符**：`therap*` → therapy / therapies / therapeutic

### 2. 必备过滤器（Essential Filters）
- **研究类型**：Clinical Trial / Systematic Review / Meta-Analysis——按研究设计筛
- **发表时间**：新的证据优先，老研究可能已被推翻
- **免费全文**：可访问性有限时用；但别因此忽略付费的高质量研究
- **Humans 过滤**：排除动物实验（回答临床问题时很有用）
- **语言过滤**：无法翻译时才用

### 3. 证据等级（Study Hierarchy）⭐
从高到低：

| 等级 | 研究设计 | 用途 |
|---|---|---|
| 最高 | 系统综述 / 荟萃分析（Meta-Analysis） | 综合多项研究，成熟领域的起点 |
| 高 | 随机对照试验（RCT） | 干预类问题的金标准（但并非所有问题都能用 RCT 回答） |
| 中 | 队列研究（Cohort） | 长期结局、罕见暴露 |
| 中 | 病例对照（Case-Control） | 罕见疾病 |
| 低 | 病例报告（Case Report） | 有趣，但不可推广 |
| — | 指南（Guidelines） | 检查是谁写的、什么时候写的 |

### 4. 批判性评价（Critical Appraisal）
- **样本量**：小样本可能显示无法重复的效应
- **看置信区间，不只看 p 值**：窄置信区间 + 有意义的效应量 > p<0.05
- **资金来源与利益冲突**：产业资助的研究往往偏向赞助方
- **主要结局 vs 次要结局**：警惕"挑显著的次要结局来宣传"
- **ITT vs PP 分析**：意向性分析（ITT）更保守、更贴近真实

### 5. 常见陷阱（Common Traps）
- 摘要结论常**夸大**结果 → 读方法学和结果部分
- **单篇研究极少定论** → 找重复验证和系统综述
- **统计显著 ≠ 临床显著**：1% 的改善对患者可能毫无意义
- **被撤稿的论文仍会出现在检索结果里** → 查 Retraction Watch
- **掠夺性期刊**（Predatory Journals）发低质量研究 → 核实期刊声誉
- **预印本**（Preprints）未经同行评审 → 快但未审核

### 6. 检索策略（Search Strategy）
- **PICO 框架**：Patient/Population（人群）、Intervention（干预）、Comparison（对照）、Outcome（结局）
- **先宽后窄**：漏掉相关文章比多翻几页更糟
- **保存检索式**：PubMed 可在有新论文匹配时发邮件提醒
- **Related Articles**：找到一篇好文章后用"相似文章"扩展
- **引文追踪**：谁引用了这篇？顺着时间往前追研究

### 7. 评价来源（Evaluating Sources）
- **影响因子**只代表期刊声望，不代表单篇论文质量
- **第一作者 / 末位作者**通常是真正干活的和带队的人
- **通讯作者**负责答疑，可联系澄清
- 看**作者单位**（机构声誉）
- **方法学部分**决定结果是否可信——结果的质量取决于方法的质量

### 8. 按问题类型选研究设计 ⭐

| 要回答的问题 | 首选研究设计 |
|---|---|
| 疗效（Treatment efficacy） | RCT + 系统综述 |
| 诊断准确性（Diagnosis） | 敏感性/特异性研究 |
| 预后（Prognosis） | 长随访队列研究 |
| 病因/危害（Etiology/Harm） | 队列或病例对照 |
| 预防（Prevention） | 有 RCT 用 RCT，否则队列 |

### 9. 实操技巧（Practical Tips）
- PubMed 免费，但**全文常要付费**：查机构访问权限、**Unpaywall**，或直接找作者要
- **PMID** 是唯一标识符，用于精确引用
- 导出到**文献管理器**（EndNote、Zotero）——手动引用易出错
- **Clinical Queries** 过滤器：预筛临床相关性（治疗/诊断/预后/病因）
- **Similar Articles / Cited By**：算法扩展发现相关工作

### 10. 论文红旗（Red Flags in Papers）
- 干预研究**没有对照组**
- 结论**不被所呈现的数据支持**
- 统计分析方法**缺失或不充分**
- **选择性报告**结局
- **未披露利益冲突**
- **非凡的主张却无非凡的证据**

### 11. 输出类型
- **类型**：`guidance` / `markdown`
- **格式**：面向生物医学文献检索与评价的 Markdown 指导文本
- **其他**：无代码、无持久化、无凭证处理、无隐藏行为

### 已知风险（厂商自述，共两条）

1. **语言过滤可能排除相关的非英文生物医学证据**
   → 缓解：仅在符合研究问题且有翻译资源时才用语言过滤
2. **检索与评价指导仍可能导致不完整或夸大的结论**（若用户只依赖单篇论文或弱设计研究）
   → 缓解：优先看系统综述、荟萃分析、合适的研究设计、重复验证和方法学审查，再据此决策
